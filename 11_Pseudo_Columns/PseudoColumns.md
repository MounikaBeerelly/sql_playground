## Pseudo Columns :

- Pseudo Columns are not part of the table, but which we can use with SELECT statement.
-  A pseudo-column behaves like a table column but is not actually stored in the table.
- They cannot be inserted or updated like normal columns.
- They are generated by Oracle when a query is executed.
- They are useful for row numbering, identifying rows, hierarchical queries, and sequence generation.
- **ROWNUM**
    - Assigns a unique number to each row returned by a query
    - EXAMPLES:
    ```
    SELECT ROWNUM, ENAME, Sal, Deptno FROM Emp
    ;
    ```
    ```
    SELECT ROWNUM, ENAME, Sal, Deptno
        FROM Emp
    WHERE Deptno = 30
    ;
    ```
    ```
    SELECT ROWNUM, ENAME, Sal
        FROM Emp
    WHERE ROWNUM = 1
    ;
    ```
    ```
    SELECT ROWNUM, ENAME, EMPNO
        FROM emp
    WHERE ROWNUM <= 5
    ;
    ```
- Doesn't give records
    ```
    SELECT ROWNUM, ENAME, Sal
        FROM Emp
    WHERE ROWNUM >= 5
    ;
    ```
    ```
    SELECT Ename, LPAD('*', ROWNUM, '*') SelectGraph
        FROM Emp
    ;
    ```
- Top N Query
    ```
    Wrong Way
    ---------

    SELECT ROWNUM, Ename, Sal
        FROM Emp
    WHERE ROWNUM < 6
    ORDER By Sal;

    Wright Way
    -----------

    SELECT *
        FROM (SELECT Ename, Sal, Deptno, Job
            FROM Emp
        ORDER BY Sal DESC)
    WHERE ROWNUM < 6
    ```

- **ROWID**
    - Represents the physical address of the row in the database
    - Oracle can directly locate and update the row using its physical address, making it very efficient.
    - EXMAPLES:
    ```
    SELECT ROWID, Ename, Sal, Deptno
        FROM Emp
    ;
    ```
